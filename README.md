# Transaction Ledger - Project Overview

A modern, highly-functional personal finance management application built with React and Capacitor, featuring AI-powered receipt scanning, wealth management, and a premium glassmorphic UI.

## 🚀 Tech Stack

- **Frontend**: React 19, Vite 7
- **Database/Auth**: Firebase
- **Styling**: Vanilla CSS with Glassmorphism
- **Mobile**: Capacitor 8 (Android & iOS)
- **AI/ML**: Google Gemini Flash (Receipt Analysis), Tesseract.js (OCR)
- **Data Visualization**: Chart.js
- **Exports**: jsPDF (Financial Reports)

## ✨ Key Features

### 1. Financial Management
- **Transaction Tracking**: Comprehensive income and expense logging.
- **Bulk Import**: Support for adding multiple transactions.
- **Reporting**: Monthly and yearly summaries with spending insights.

### 2. Advanced Wealth Tools
- **Portfolio Manager**: Track investments and net worth.
- **Wallet Manager**: Organize finances across multiple accounts.
- **Subscription Manager**: Monitor recurring payments.
- **Debt Manager**: Keep track of loans and money owed/lent.

### 3. AI Receipt Scanning
- **Shared Receipt Processor**: Automatically extract data from receipt images using Gemini AI.
- **Share Target Integration**: Receive images directly from other mobile apps.

### 4. Security & Privacy
- **App Lock**: Secure PIN-based entry.
- **Privacy Mode**: "Ghost Mode" to hide sensitive figures.

### 5. Mobile & Offline Experience
- **Progressive Web App (PWA)**: Works offline.
- **Haptic Feedback**: Premium tactile interactions.
- **PDF Export**: Generate professional financial reports.
